# عبدالرحيم محمد أمين — الموقع الشخصي

موقع تعريفي من صفحة واحدة لـ **عبدالرحيم محمد أمين**، مدير الموارد البشرية لشركة شؤون الغذاء
لتطوير وإدارة المطاعم وشركة سنام الرائدة.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | الموقع كامل — HTML و CSS و JavaScript في ملف واحد، بدون أي مكتبات خارجية |
| `portrait.webp` | صورة الواجهة (خلفية شفافة) |
| `photo2.webp` | صورة قسم النبذة |
| `shoun.webp` · `sanam.webp` | شعارا الشركتين |
| `hashi.webp` · `tahameiah.webp` · `dawar.webp` · `mashwiyah.webp` · `hiraa.webp` · `shawaya.webp` · `etlalah.webp` | شعارات العلامات التجارية |
| `favicon.svg` | أيقونة التبويب |
| `.nojekyll` | يمنع GitHub Pages من معالجة الملفات بـ Jekyll |

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى فرع `main` في المستودع.
2. من `Settings` ← `Pages`: اختر **Source: Deploy from a branch**، والفرع `main` والمجلد `/ (root)`.
3. انتظر دقيقة، ثم افتح: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### ربط دومين خاص

1. أضف ملف باسم `CNAME` في جذر المستودع يحتوي على سطر واحد: اسم الدومين (مثال: `abdulrahim.sa`).
2. عند مزوّد الدومين أضف سجلات `A` لـ apex تشير إلى: `185.199.108.153` · `185.199.109.153` · `185.199.110.153` · `185.199.111.153`
3. لنطاق فرعي (`www`) أضف سجل `CNAME` يشير إلى `<اسم-المستخدم>.github.io`
4. من `Settings` ← `Pages` فعّل **Enforce HTTPS**.

## التعديل

كل المحتوى (العلامات التجارية، الفروع، مجالات الخبرة، وحدات المنصة) في مصفوفات JavaScript
أعلى وسم `<script>` في `index.html` — عدّلها مباشرة بدون لمس التصميم.

رقم الواتساب موجود في ثابت `WA_NUM` قرب نهاية الملف، وفي روابط `wa.me` داخل الصفحة.

> ملاحظة: رمز QR في قسم التواصل يشفّر رابط الواتساب (`wa.me/966593394514`) وليس عنوان الموقع،
> لذلك يبقى صالحاً حتى لو تغيّر الدومين.
